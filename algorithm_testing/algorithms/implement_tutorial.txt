#  structured so the metrics work automatically.

===============================================================
1. INPUT YOUR FUNCTION RECEIVES
===============================================================
Your algorithm MUST have exactly this signature:

    def run_algorithm(G, entry, items, checkouts):

Parameters:
- G         : NetworkX graph (with weight on edges, x/y on nodes)
- entry     : Start node (e.g. "21")
- items     : List of target nodes (e.g. ["41","61","59"])
- checkouts : List of possible end nodes (e.g. ["14","15"])

Nothing else is needed.


===============================================================
2. OUTPUT YOUR FUNCTION MUST RETURN
===============================================================
Your algorithm MUST return a dict, EXACTLY like this:

    {
        "order": [...],          # logical order of stops
        "walk": [...],           # complete node sequence in the graph
        "total_distance": float  # length of the walk
    }

Details:

"order"
    The order of important waypoints:
    Example: ["21", "41", "61", "59", "14"]

"walk"
    The full route in the graph, including all intermediate nodes.
    Example: ["21","22","23","41","42","61","59","58","14"]

"total_distance"
    A float, the distance along the walk.


===============================================================

===============================================================
4. RULES
===============================================================
- No classes
- No other return format
- No prints
- No inputs
- No plotting
- No global dependencies

Only:
    run_algorithm returns a dict


===============================================================
5. EXAMPLE: BnB (shortened, correctly formatted)
===============================================================
    def run_algorithm(G, entry, items, checkouts):
        relevant = [entry] + items + checkouts
        dist, spath = compute_pairwise_dijkstra(G, relevant)

        if items:
            best_order, best_cost = bnb(entry, items, 0.0, [entry], dist, checkouts, (None, float("inf")))
        else:
            best_order = [entry] + [min(checkouts, key=lambda c: dist[entry][c])]
            best_cost = dist[entry][best_order[-1]]

        walk = []
        for a, b in zip(best_order[:-1], best_order[1:]):
            seg = spath[a][b]
            walk.extend(seg if not walk else seg[1:])

        return {
            "order": best_order,
            "walk": walk,
            "total_distance": float(best_cost)
        }


===============================================================
6. WHY THIS STRUCTURE?
===============================================================
So the testbench works automatically:

    results = evaluate_all_criteria(
        run_algorithm,
        G,
        entry,
        items,
        checkouts
    )

And we get:
- Distance
- Turns
- Runtime
- Comparability across all algorithms
