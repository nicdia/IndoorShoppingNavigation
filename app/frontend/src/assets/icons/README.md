# Icons

Place reusable SVG/PNG assets for the frontend here, e.g.:

- `checkout-pin.svg` – marker used inside `MapPreview`
- `favicon.svg` / `logo.png` – browser tab icon or general branding

Import paths from React code can reference icons relative to `src/assets/icons`, e.g.

```ts
import CheckoutPin from "../assets/icons/checkout-pin.svg";
```

Add new files to this folder and Vite will include them in the build.
